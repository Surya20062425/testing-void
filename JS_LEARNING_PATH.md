# JavaScript Beginner → Pro: Project-Based Learning Path

## Phase 1: Foundations (Weeks 1-3)
**Core concepts:** Variables, functions, control flow, DOM manipulation, events

| Project | Key Skills |
|---------|------------|
| **1. Calculator** | Functions, event listeners, DOM updates, basic math |
| **2. Todo List (localStorage)** | CRUD, localStorage, array methods, event delegation |
| **3. Stopwatch/Timer** | `setInterval`/`setTimeout`, state management, formatting |
| **4. Form Validator** | Regex, constraint API, accessibility, preventDefault |

---

## Phase 2: Intermediate (Weeks 4-7)
**Core concepts:** Async JS, fetch/API, modules, array/object methods, error handling

| Project | Key Skills |
|---------|------------|
| **5. Weather App (OpenWeather API)** | `fetch`, async/await, error handling, template literals |
| **6. GitHub User Search** | API pagination, debounce, AbortController, loading states |
| **7. Markdown Previewer** | `marked` library, textarea sync, sanitization (DOMPurify) |
| **8. Pomodoro Timer with Audio** | Web Audio API, notifications API, settings persistence |

---

## Phase 3: Advanced Patterns (Weeks 8-12)
**Core concepts:** Closures, prototypes, `this`, modules, design patterns, testing

| Project | Key Skills |
|---------|------------|
| **9. Mini State Management (Redux-like)** | Pub/sub, immutability, middleware, devtools |
| **10. Component Library (Vanilla)** | Custom elements, Shadow DOM, slots, lifecycle |
| **11. Drag-and-Drop Kanban Board** | Pointer events, Sortable logic, localStorage sync |
| **12. Unit Test Suite (Vitest/Jest)** | TDD, mocking fetch, coverage, CI basics |

---

## Phase 4: Ecosystem & Tooling (Weeks 13-16)
**Core concepts:** Build tools, TypeScript, linting, bundling, deployment

| Project | Key Skills |
|---------|------------|
| **13. Vite + TS + ESLint + Prettier Setup** | Config from scratch, path aliases, env vars |
| **14. Full-Stack App (Node/Express + Vanilla FE)** | REST API, JWT auth, cookies, CORS, deployment |
| **15. Real-time Chat (Socket.io)** | WebSockets, rooms, typing indicators, reconnection |
| **16. Chrome Extension (MV3)** | Service workers, content scripts, storage, messaging |

---

## Phase 5: Pro Level (Weeks 17+)
**Core concepts:** Performance, architecture, security, open source, specialization

| Project | Key Skills |
|---------|------------|
| **17. Build a Bundler (esbuild-style)** | AST, parsing, transformation, code splitting |
| **18. Open Source Library (npm publish)** | Semver, changelog, CI/CD, docs, types |
| **19. Performance Audit Tool** | Lighthouse CI, Web Vitals, bundle analysis, profiling |
| **20. Specialize** — pick one: **Node internals** / **WebGL/Three.js** / **Electron/Tauri**
